// MinUI (the rg35xxplus platform) and NextUI (the h700 platform) both read this
// file, and SDL picks the line whose GUID matches the pad. DEVICE is deliberately
// not used to choose between them: MinUI reports DEVICE=hdmi whenever a cable is
// attached, and NextUI falls back to DEVICE=rg35xxplus for any model it does not
// know.
//
// From NextUI v6.14.0-rc11, SDL reports the built-in controls on every H700
// model under the single 19000000010000000100000000016e01 GUID, with the same
// button numbers as the TrimUI devices. Its line keeps a on the button labelled
// A, as the tg5040 mapping does.
//
// The Deeplay-keys and Anbernic-RGCubeXX lines are the pads MinUI reports, and
// NextUI before rc11. Bytes 3 and 4 of each of their GUIDs are a CRC16 of the
// name the kernel reports, and a crc: field overrides them, so each line's crc:
// has to match its own GUID.
